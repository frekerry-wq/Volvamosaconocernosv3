# Volvamos a conocernos

Pagina web interactiva para reconectar en pareja.

## Como personalizar
Abre `script.js` y edita:
- `START_DATE` (linea ~8) — fecha de inicio de la relacion
- `TIMELINE` — los momentos de su historia
- `REASONS` — las razones por las que la amas
- `TF` — preguntas de verdadero/falso

## Como leer las respuestas
En el menu, toca 7 veces la estrellita del fondo para abrir la seccion "Para ti".
